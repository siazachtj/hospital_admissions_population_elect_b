# Singapore Population Ageing & Healthcare Utilization Analytics Platform

A Python-based healthcare analytics platform that integrates Singapore public healthcare and demographic datasets into a registry-style relational database to support population health analysis, healthcare utilization forecasting, and regional healthcare burden assessment.

This project demonstrates healthcare data engineering, statistical analysis, dashboard development, and operational healthcare analytics using real datasets from data.gov.sg.

---

## Objectives

- Build automated ETL pipelines using Singapore government APIs
- Design a registry-style relational database architecture
- Analyze population ageing and healthcare utilization trends
- Forecast future healthcare demand
- Develop an interactive operational analytics dashboard

---

## Technologies

- Python
- Pandas
- SQLite
- SQLAlchemy
- Scikit-learn
- Streamlit
- Plotly
